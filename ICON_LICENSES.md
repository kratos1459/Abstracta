# Icon licences

Abstracta bundles 1295 icons from [Bioicons](https://bioicons.com) ([duerrsimon/bioicons](https://github.com/duerrsimon/bioicons)). Each icon keeps its own licence and author, listed below. Share-alike (CC BY-SA) icons were left out on purpose.

Icons under CC BY need a credit line wherever a figure that uses them is published. The app generates that text automatically (Credits panel, and a `_credits.txt` file with every export).

The 42 icons in the "Abstracta" categories were drawn for this project and are released under the MIT licence with the rest of the code.
